# Spine Community — 首次访问用户端到端体验测试（2026-11-10）

## 目的
从未登录的首次访客和新注册普通会员的角度，验证站点的基础使用闭环。测试使用 Chrome 浏览器自动执行；未将测试帖子、测试账号或评论写入生产环境。

## A. 生产网站：真实访客、只读测试
- 地址：`https://spine.nbn369.com/`
- 运行：GitHub Actions [Novice visitor browser UX audit #42775778561](https://github.com/119shenhao/spine-community/actions/runs/42775778561)
- **结果：14/14 PASS，0 FAIL**，无捕获到未处理的 JavaScript 异常。
- 通过步骤：正式网站首页 HTTP 200；首页渲染 20 张帖子卡片；帖子正常 URL；点击进入详情 SPA 无刷新导航；直达帖子 URL 返回已包含帖子正文的服务端 HTML 且 SPA 能接管；未登录点击回复、点赞、收藏均提示登录（不进行写操作）；登录弹窗正常关闭；搜索 `back pain` 并产生正常 History API URL；切换简体中文及英文；访问个人中心提示登录；浏览器前进和后退；390px 手机视口从首页进入帖子和打开登录弹窗。
- 登录弹窗中真实显示 `/api/auth/google`，**未点击进入 Google OAuth，以免创建生产 OAuth 状态及产生真实账号操作**。
- 通过这些步骤不能保证 iOS Safari/其他移动设备均无问题，也不能替代真实 Google 授权成功及回调测试。

## B. 隔离本地环境：模拟已登录的普通会员
- 运行：GitHub Actions [Isolated newcomer signed-in UI test #42776230206](https://github.com/119shenhao/spine-community/actions/runs/42776230206)
- **结果：11/11 PASS，0 FAIL**。
- 采用 GitHub runner 上的 Cloudflare Wrangler local + 本地 D1，预先植入两个**仅存在于一次性本地数据库**的虚构普通会员会话，用真实前端 Chrome 与真实 Worker API 完成操作；不依赖或伪造正式 Google OAuth。
- 通过步骤：登录态显示会员身份；通过网页发布首帖；根回复无页面刷新；楼中楼回复；点赞/取消点赞；收藏并在「我的收藏」中找到帖子；修改用户昵称并看到即时变更；第二位模拟会员回复后，楼主收到通知；通过搜索找到刚发表的帖子；退出登录后返回游客界面；无未处理 JS 异常。
- 测试账号、帖子、回复仅存在于 CI 的隔离本地数据库，未同步至生产或预览 D1。

## 结论和边界
- 这两轮覆盖核心的 **访客打开网站 → 搜索/阅读/语言切换 → 登录入口 → 已登录会员发帖/回复/互动/个人资料/通知 → 退出登录** 体验，合计 **25/25 步通过**，本轮没有观察到阻断性的页面交互问题。
- **未实测完整 Google OAuth 登录授权**，尤其是 Google 授权页面、回调、真实账号创建、生产 Cookie/会话持久化；不能宣称真实生产登录全链路通过。需在有真实测试账号的授权浏览器里补测。
- 未在生产库做任何状态改变、数据新增、发布、删除或测试留言。本轮也未覆盖全量翻译、审核举报、康复进展、跨设备兼容性、极慢网络或高并发压力。
- 后续建议：在 ChatGPT Work 或经用户授权的真实浏览器中，使用测试用 Google 账号补测一次登录回调、发帖、回复、退出，并人工检查 iPhone Safari 的触控与表单布局。
