# Post sharing / 帖子分享

## 用户需求（2026-11-13）

在每篇**公开已发布**帖子的详情页顶部显示“分享”按钮。点击时提供 Facebook、X、Reddit、LinkedIn、WhatsApp、Telegram、Bluesky 的平台分享链接，手机浏览器支持 Web Share API 时提供系统分享，另外始终有复制帖子链接功能。未登录访客也可分享。被删除、隐藏、未发布的内容不展示公开分享入口。

## 实现规则

- 分享网址采用当前站点源地址和 /topic/{id} 独立 History API 路由；不携带临时评论定位、查询参数或追踪参数。开发预览分享开发链接，生产分享生产链接，避免将未发布的开发帖误指向生产。
- 分享标题使用帖子的原始标题，社交网站通过对应主题页已有的 Open Graph 元信息预览内容。
- 所有分享必须由访客明确点击触发，站点不主动加载第三方 SDK、嵌入件或跟踪脚本；使用普通安全外链（noopener/noreferrer）。对于没有通用网页分享端点的社交 App，可以使用系统分享或复制链接粘贴。
- 打开菜单、复制链接不刷新或重新获取帖子，不增加 Worker 或 D1 请求；不需要新数据表、数据库迁移或后端 API。
- 界面提供英文、简体中文、繁体中文、西班牙语、巴西葡萄牙语、德语、法语、日语翻译。
- iPhone/Android、电脑端均应可正常操作。Web Share API 取消分享不报错；复制链接失败显示提示并保留可手动选中的链接。
- 开发优先在 `feature/v1-community-build-20261106` 完成，生产发布须另外执行既定“发布新版本”任务，不由本次功能开发自动发布。

## 验收

1. 公开帖子详情页标题上方存在分享按钮，未登录也可用；未公开帖子不可分享。
2. 各平台链接 URL 参数正确且包含帖子独立地址和标题（视平台接受参数而定）。
3. 点击复制链接并从链接打开帖子能直达详情；移动端系统分享可用时显示额外选项，系统取消不报错。
4. 无完整页面刷新、无无关 API 请求；按钮和弹窗在窄屏、全部支持语言下可用。
