# 个人中心、隐私权限与删帖规则（2026-11-06）

> 状态：本轮讨论已确认的第一版范围，具体接口、保留期限和法律合规方案尚未定稿。本文只记录需求，不代表已经开发。

## 个人中心（第一版已确认）
- 采用**最小版个人中心**，包含「我的帖子」「我的回复」「我的收藏」和「我关注的帖子／进展提醒」入口；可使用已有的站内通知列表。
- 收藏列表点击后直接跳回原帖；收藏和关注独立，不自动互相转换，也不因为收藏收到楼主进展通知。
- 第一版不做复杂的个人主页设计、成就等级、收藏分类或标签功能。
- 账号基础信息应支持公开昵称与语言偏好；复杂的个人资料管理细节后续设计。

## 隐私和权限（已确认）
- 普通用户可使用**匿名昵称**，不强制公开真实姓名。帖子默认属于公开内容，发布前提示用户避免公开真实姓名、联系方式、具体住址及医疗隐私。
- Google 邮箱、外部登录标识、登录令牌和会话凭证**不对普通用户或版主公开**。系统必须以服务端身份验证和权限判断控制访问。
- **站长具有最高业务管理权**，可以管理公开及被举报／隐藏的内容、账号状态、分类、版主、审核和统计等；但“最高权限”不等于界面可以直接显示 Google 登录令牌、会话密钥等机密。敏感凭证不应作为后台可读资料。
- **版主最小权限**：仅可访问处理审核和临时禁言所需的信息，不可读取不必要的私人账号资料或修改患者原文。
- 应支持账号注销和个人数据删除申请；具体身份核验、依法保留事项、数据导出与期限，在正式上线前明确，不能将“申请删除”误解为后台立即清空所有相关第三方讨论。

## 删除主帖及其回复（已确认）
- 当**楼主删除自己发布的主帖**且已有其他用户回复时，**保留“该帖子已删除”的占位以及讨论关系**，其他人的回复继续可见，不因删除主帖整串消失。
- 删除后不再公开主帖原文或机器译文；需同步清理／使搜索索引、翻译缓存和页面缓存失效，防止通过正常公开途径恢复已删文字。
- 这与之前已经确认的**删除有子回复的评论保留占位**相一致。占位只保留讨论结构所需的标识，不能继续展示患者已删除的健康文本。
- 无下级回复的主帖或评论如何删除、后台存储保留期和法规要求仍待实现阶段确定，不能擅自把“占位”理解为无期限保留正文。

## 后续待细化
- 账户注销后的关联显示、举报正在审核时的删除处理、数据保留和申诉期限、昵称设置及个人中心具体交互。
- 公开上线前完成隐私政策、服务条款、年龄要求以及第三方翻译处理患者文本的告知和控制。
