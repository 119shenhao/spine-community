# 楼主进展更新（2026-11-06 已确认）

> 仅需求文档，不代表功能已开发。

## 第一版范围
- 暂不开发独立“康复日记”模块；先让楼主在原帖里不定期更新症状变化、康复情况、检查结果或治疗调整。
- 只有**原帖楼主**能使用“更新进展”按钮。它本质是**楼主回复自己的帖子**，复用已有评论和楼中楼系统，区分为一种特殊的“进展更新”回复。服务端也应验证楼主身份。
- 自动显示更新日期及“楼主第 N 次更新”；具体编号和删除后的顺序规则在实现阶段明确。

## 展示：双入口、单条数据
- 原帖正文下方增设“楼主进展”汇总，默认露出**最近 1～2 条**，点击“查看全部进展”按时间线查看。
- 同一进展**也显示在普通回复列表**，标注“楼主进展”。点击顶部汇总中的记录可以定位至评论区的对应进展。
- 两处只是展示入口；每条进展仅保存**一份数据和一个稳定 ID**，不能重复创建评论、点赞和通知记录。

## 评论、点赞、通知
- **任何已登录用户，包括楼主，都可以回复每次进展**，继续楼中楼讨论，也可以点赞、取消点赞。游客可以阅读公开内容，但不能回复或点赞。
- 楼主可编辑、删除自己的进展。删除后如果存在下级回复，沿用已确认规则：保留“该评论已删除”占位与下级讨论，不再公开已删除内容或译文。
- 他人对楼主进展及其回复的评论、点赞，沿用已确认的站内通知规则；自己回复或给自己点赞，不通知自己。
- **尚未决定**：楼主每次更新后，是否自动通知此前讨论的用户；“关注帖子并订阅进展”目前仅为后续建议，不算第一版已确认。
