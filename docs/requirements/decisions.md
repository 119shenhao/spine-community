# Spine Community — 需求决定记录

> 本文记录产品决定，不代表功能已完成。详细规则见同目录文档。

## 2026-11-06 — 症状搜索（已确认）
- 关键词搜索和四个可选筛选：身体部位、症状标签、持续时间、治疗方式。
- 全球所有语言共同检索，跨语言症状匹配；默认展示界面语言译文，可看原文，搜索词高亮。
- 结果卡片显示标题、标签、摘要、时间、作者自愿公开地区和原文语言。
- 默认最相关，也可选最新或讨论最多；至少匹配一项症状／部位（一般关键词搜索除外），匹配越多通常越靠前。
- 每次加载 20 条，下滑加载更多。
- 无完全匹配时自动展示标明差异的“相似结果”，提供调整搜索或发帖入口。
- 详见 [症状搜索需求](search-progress-2026-11-06.md)。

## 2026-11-06 — 楼主进展更新（已确认）
- 第一版不设独立康复日记；楼主点击“更新进展”，在原帖里发布特殊类型回复。
- 进展显示日期和次数，正文下方“楼主进展”汇总和普通回复列表双入口、单条数据。
- 已登录用户可回复进展、楼中楼及点赞；沿用已定的编辑删除和通知规则。
- 更新进展是否主动通知之前参与者**未确认**。
- 详见 [楼主进展更新需求](author-progress-2026-11-06.md)。
