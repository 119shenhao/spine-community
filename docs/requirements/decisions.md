# Spine Community — 需求决定记录

> 本文记录产品决定，不代表功能已完成。详细规则见同目录文档。

## 2026-11-06 — 症状搜索（已确认）
- 关键词搜索和四个可选筛选：身体部位、症状标签、持续时间、治疗方式。
- 全球所有语言共同检索，跨语言症状匹配；默认展示界面语言译文，可看原文，搜索词高亮。
- 结果卡片显示标题、标签、摘要、时间、作者自愿公开地区和原文语言。
- 默认最相关，也可选最新或讨论最多；至少匹配一项症状／部位（一般关键词搜索除外），匹配越多通常越靠前。
- 每次加载 20 条，下滑加载更多。
- 无完全匹配时自动展示标明差异的“相似结果”，提供调整搜索或发帖入口。
- 详见 [症状搜索需求](search-progress-2026-11-06.md)。

## 2026-11-06 — 楼主进展更新（已确认）
- 第一版不设独立康复日记；楼主点击“更新进展”，在原帖里发布特殊类型回复。
- 进展显示日期和次数，正文下方“楼主进展”汇总和普通回复列表双入口、单条数据。
- 已登录用户可回复进展、楼中楼及点赞；沿用已定的编辑删除和通知规则。
- **已确认**：第一版支持用户主动关注某篇帖子；楼主发布进展更新时，向该帖关注者发送站内通知。以前评论过但未关注的用户不因进展更新收到订阅提醒；暂不做关注楼主本人。
- 详见 [楼主进展更新需求](author-progress-2026-11-06.md)。

## 2026-11-06 — 收藏帖子（已确认）
- 第一版支持已登录用户**收藏帖子**；未登录游客可以浏览，但不能收藏。
- 个人中心提供“我的收藏”列表；点击收藏项**直接打开原帖**，不另设康复进展摘要页面。
- 首版**不提供收藏分类、文件夹或自定义标签**。
- “收藏”与“关注帖子”是**两个独立操作**，互不自动触发；只收藏不会订阅楼主进展或收到进展通知。
- 用户使用收藏主要为了以后找回有价值的内容、回顾患者经历和比较相似情况。
- 取消收藏按钮样式、列表排序等尚未单独确认，留待交互细节设计。

## 2026-11-06 — 后台管理、举报及统计（已确认）
- **发布审核**：普通内容先发布后审核；规则识别垃圾内容分三级：低风险发布，中风险保存待审核（作者可见），高风险自动拦截并允许复核。首版不用付费 AI 审核。
- **举报流程**：登录后可举报帖子与评论，同一用户对同一内容仅一条有效举报，原因及说明记录在后台。举报不直接自动删除，严重风险优先处理；**举报人数多也不单凭数量自动隐藏**，避免恶意举报。处理结果留管理记录并支持申诉。
- **后台权限**：站长＋版主两级角色，最初仅站长账号实际运营。版主可处理举报、隐藏／恢复内容、临时禁言（1／3／7／30 天）；永久封禁、永久删除、任命版主、分类管理、配置等仅站长。管理者不能改写患者原文，不应无必要查看敏感账号信息。
- **操作日志**：记录管理员、时间、对象、操作、原因。
- **每天基础统计**：注册人数、发帖数、评论数、举报数；另外统计 UV、PV、五分钟窗口独立活跃人数的**峰值估计**、最高每小时 PV 及其时段。支持最近 7／30 天趋势，不做实时大屏；**首版不按国家拆分流量**。
- 详细规则和技术待定细节见 [后台管理、举报与统计需求](admin-moderation-analytics-2026-11-06.md)。

## 2026-11-06 — 个人中心与隐私、删帖占位（已确认）
- 第一版个人中心采用最小范围：「我的帖子」「我的回复」「我的收藏」「关注帖子／进展提醒」；不做复杂个人主页。
- 用户可使用匿名昵称，不要求公开真实姓名；帖子默认公开并提示避免发布个人身份与健康隐私。
- 站长拥有最高业务管理权限，但不在后台明文展示 Google 登录令牌、会话密钥等机密；版主仅访问审核所必需的信息。
- 用户可申请账号注销与个人数据删除；具体合规、数据保留和导出流程上线前细化。
- **删除已有回复的主帖时保留“该帖子已删除”的占位，其他用户的回复继续保留**；已删主帖的原文、机器译文、搜索和公开缓存不得继续展示。与先前确认的评论删除占位一致。
- 详见 [个人中心、隐私与删帖](profile-privacy-deletion-2026-11-06.md)。
