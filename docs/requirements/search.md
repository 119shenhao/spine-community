# 症状搜索需求（2026-11-06 已确认）

本文件只记录需求，未修改代码或数据库。

## 搜索与筛选
- 一个关键词搜索框，四项**选填**条件：身体部位（颈部、腰部、颈腰均有等）、症状标签、持续时间、治疗方式。
- 发帖仍只需标题和正文，分类及症状均可空；未分类帖子可以通过正文搜索。
- 默认搜索**所有语言**的公开帖子。中文词可以匹配英文等其他语言的相似症状，采用统一症状概念 ID、多语言同义词、关键词扩展和全文搜索。译文缓存仅辅助，不能依赖缓存已生成才可搜索；复杂 AI 语义理解留待后续。
- 结果默认翻译成读者的界面语言，同时标出原文语言并可切换查看原文；翻译失败时显示原文。标题和摘要里**高亮**命中关键词及其跨语言对应含义。
- 默认排序“最相关”，可切换“最新”和“讨论最多”。症状搜索**至少匹配一项症状或部位**才进入结果；匹配项越多通常越靠前。普通搜索（如康复经验）不强制匹配症状。用户手动选择的筛选对正常搜索结果严格生效。
- 结果展示**标题、标签、自动摘要、时间、作者自愿公开的地区、原文语言**。地区不填写就不显示，不能推断位置。一次加载 **20 条**，向下滑动加载更多。

## 无结果处理
- 无完全匹配时，提示并**自动展示“相似结果”**，明确说明匹配项及未匹配项；仍须通过最低相关门槛。
- 原条件不悄悄改动；推荐内容若放宽某个筛选，须标明放宽项，并和严格结果分区展示。
- 提供调整筛选、换关键词、发布求助帖入口；网络错误与无结果分开提示。相似症状不等于相同诊断。
- “久坐疼”“晨起疼”可通过正文或词典检索；第一版核心筛选仍是上述四项。
